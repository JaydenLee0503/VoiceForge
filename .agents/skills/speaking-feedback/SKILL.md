---
name: speaking-feedback
description: Implement mock and real post-session speaking feedback features for VoiceForge. Use when building results, summaries, scorecards, transcript highlights, or coaching feedback around speaking performance.
---

When using this skill:
- focus on clarity, confidence, pace, eye contact/presence, filler words
- keep scoring simple and interpretable
- prioritize useful summary cards over complex analytics
- do not attempt phoneme-level pronunciation scoring for MVP

Workflow:
1. Start with the smallest useful feedback surface.
2. Model scores so a user can understand them at a glance.
3. Prefer summary cards, highlights, and next-step coaching over dense charts.
4. Keep feedback copy practical, calm, and product-aligned.
5. Add richer analytics only when the MVP surface is already clear.
